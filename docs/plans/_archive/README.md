# Archived plans

Shipped/superseded per-ticket plans land here. The `cadence-deliver` **CLOSE** phase moves a plan here automatically after SHIP and stamps a header:

```
> SHIPPED 2026-06-19 | PR #N | CAD-N | release vX.Y.Z
> Archived from active plans — do not modify; superseded by code + the ADR(s) it cites.
```

Active, in-flight plans live one level up in `docs/plans/`. Agents must NOT treat an archived plan as current behaviour — read the code and the ADRs it references instead.
