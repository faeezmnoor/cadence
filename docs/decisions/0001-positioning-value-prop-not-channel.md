# 0001 — Positioning: lead with the value prop, never the channel

- Status: accepted
- Date: 2026-05-29
- notion: D-001

## Context
Cadence delivers to Telegram, but the channel is a delivery detail, not the value. Channel-first framing undercuts the moat (chat-config + self-learning loop) and invites "it's just a Telegram bot" dismissal.

## Decision
Lead with **"Your own market researcher at a fraction of the cost."** Telegram is mentioned only in passing. Anti-positioning (locked): NOT a Bloomberg/equity-research replacement, NOT a price/flight alert tracker, NOT a newsfeed/aggregator, NOT a "Telegram bot", NOT a chat assistant, NOT a subscription.

## Consequences
All marketing, UI, and PRDs run against this. Channel and format stay swappable behind the value prop.
